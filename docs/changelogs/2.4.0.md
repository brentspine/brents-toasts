# 2.4.0 - 2026-08-02

## Changed

- `responsiveBreakpoint` default increased from `480` px to `800` px (roughly tablet-portrait width instead of phone-portrait), better accommodating modern device sizes before collapsing left/right positions.
- `updateToast({ color })` on a manual progress bar now patches the progress fill's color in place instead of rebuilding the bar's DOM, preserving any in-flight `setToastProgress` animations instead of snapping them to their target.

## Fixed

- `updateToast({ color })` on a manual progress bar no longer interrupts active progress animations when the progress color defaults to the toast's own color.

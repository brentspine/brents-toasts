# 2.2.14 - 2026-07-26

## Added

- `ToastAnimation.NONE` animation: no transition, appears/disappears/reflows instantly.
- `registerToastAnimation()` function to define custom named animations with full control over enter/exit behavior and timing.
- `ToastAnimationDefinition` and `ToastAnimationHookContext` types for building custom animations.

## Changed

- `ToastAnimation.FADE` now fully implemented as an opacity-only animation (previously a stub).
- Animation definitions now govern a toast's motion for its entire lifetime — not just entrance, but also reflow when siblings are added/removed via the shared `containerTransition` CSS property.
- Toast animations are now resolved and stored at creation time, so removal always uses the same animation that was used for entrance.

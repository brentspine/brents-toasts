# 2.1.10 - 2026-07-24

## Added

- **`configurePosition(position, { maxToasts?, evictOldest? })`** method to override `maxToasts` and `evictOldest` per position, layered on top of the global config. Useful for independent capacity limits at different screen locations (e.g., a smaller `TOP_RIGHT` stack alongside a larger default `BOTTOM_CENTER` one).
- **`positionConfig` public field** — a `Map<ToastPositionValue, PositionConfig>` storing per-position overrides. Setting a key to `undefined` drops it back to the global config value without needing a separate clear method.
- **`PositionConfig` type** exported for consumers.

## Changed

- `maxToasts` and `evictOldest` config options are now overridable per position via `configurePosition()`.

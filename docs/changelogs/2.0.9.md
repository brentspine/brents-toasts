# 2.0.9 - 2026-07-23

## Added

- **`buttons` option** — Add action buttons to toasts via `ToastOptions.buttons` array or `ToastBuilder.withButton()` (repeatable). Buttons render as plain, underlined clickable text (not native-looking buttons) in a flex row to the right of the message, vertically centered regardless of `title` presence. `onClick(event, id)` receives the click/keyboard-activation event and the toast's id, enabling patterns like "Undo" (dismiss + show new toast) or "Details" (mutate toast DOM to reveal more). Button clicks never trigger the toast's `closable` dismissal.

## Changed

- Toast content now uses `flex: 1 1 auto; min-width: 0` to accommodate buttons alongside the message without overflow issues.

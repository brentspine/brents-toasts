# 2.1.8 - 2026-07-23

## Added

- Demo UI control to select all six toast positions (TOP_CENTER/TOP_LEFT/TOP_RIGHT/BOTTOM_CENTER/BOTTOM_LEFT/BOTTOM_RIGHT).

## Changed

- **All six toast positions are now fully implemented.** Previously only `BOTTOM_CENTER` had placement CSS; top and bottom variants now work via `data-position` attribute driving vertical stacking direction and CSS selectors handling horizontal alignment (left/center/right).
- Updated documentation and comments to reflect all positions are production-ready.

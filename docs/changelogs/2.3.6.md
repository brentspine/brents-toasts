# 2.3.6 - 2026-08-02

## Changed

- `confirmButton()` now swaps the entire toast's message and buttons instead of just relabeling itself. Clicking it replaces the message with `confirmMessage` and all buttons with Yes/No pair; clicking "Yes" runs `onConfirm`, optionally flashes `doneMessage`, then restores original content; clicking "No" cancels immediately without a timer.
- `confirmButton()` options renamed: `confirmLabel` → `confirmMessage`, `doneLabel` → `doneMessage` (now accepts `null` to skip the flash), added `yesLabel`/`noLabel`. Removed `confirmTimeoutMs` (no longer needed since "No" is explicit cancellation).
- Added `yes`/`no` translations to all locale packs (`en`, `de`, `es`, `fr`).
- Demo: Config page now has a "Reset to defaults" button.
- Demo: Playground shows a hint when viewing with customized config from the Config page.
- Updated documentation and JSDoc comments to reflect the new `confirmButton()` behavior.

## Fixed

- `package.json` now includes a `files` field to ensure only `dist/` is published to npm.

# 2.3.8 - 2026-08-02

## Added

- New `responsiveBreakpoint` config option (default `480` px) that collapses `*-left`/`*-right` toast positions into their edge's `*-center` equivalent on narrow viewports, preventing overlapping stacks on mobile screens. Set to `0` to disable collapsing.
- Live position reconciliation on window resize/orientation-change, automatically moving already-shown toasts between containers as the viewport crosses the responsive breakpoint.

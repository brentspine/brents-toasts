# 2.0.10 - 2026-07-23

## Added

- **Details block** — new `details` option for displaying expandable, structured information below the toast message. Each detail item can have an optional label and value, with individual "Copy" buttons (disable per-item with `copyable: false`). An auto-added "Details" toggle button reveals/hides the block, which is structurally outside the clickable/dismissable part of the toast. Customize toggle button text with `detailsLabel` and `detailsHideLabel`. Builder: `.withDetails(details, detailsLabel?, detailsHideLabel?)`.
- `ToastDetailItem` interface exported for type safety.
- Auto-repositioning on content height changes via `ResizeObserver` — expanded details or any in-place mutations now reflow the entire stack so toasts never overlap.

## Changed

- Toast DOM structure: clickable/dismissable behavior now lives on `.bt-toast-row` instead of `.bt-toast` itself, keeping the details block (a sibling) structurally unreachable by dismiss listeners.

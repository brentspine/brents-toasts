# 2.1.6 - 2026-07-23

## Added

- `updateToast(id, update)` method to modify an already-shown toast in place (message, color, buttons, details, etc.) without removing and recreating it.
- `addToastButton(id, button, index?)` and `removeToastButton(id, index)` for incremental button changes.
- `addToastDetail(id, detail, index?)` and `removeToastDetail(id, index)` for incremental detail changes.
- `removeAllToasts()` public method to dismiss all visible toasts across all positions at once (was previously private).
- `ToastUpdateOptions` export for type hints when calling `updateToast`.

## Changed

- `closable` and `pauseOnHover` flags are now read live from toast state at event time, allowing `updateToast` to toggle them on already-rendered toasts.
- Refactored internal color/content/action-rendering logic into shared `_applyColor`, `_applyContent`, and `_renderActions` methods used by both `showToast` and `updateToast`.

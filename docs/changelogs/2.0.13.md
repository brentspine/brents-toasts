# 2.0.13 - 2026-07-23

## Added

- `detailsCopyable` option on toasts to set default copyability for all detail items at once, without repeating `copyable: false` on each one
- `buttons` array support on detail items, allowing custom action buttons per detail row with the same click/keyboard behavior as top-level toast buttons
- `.withDetailsCopyable(copyable)` builder method

## Changed

- Detail item `copyable` now defaults to the toast's `detailsCopyable` setting (which itself defaults to `true`) instead of always `true`

## Fixed

- Improved hover target for action button column in toasts by using padding instead of margin, preventing accidental hover dismissal when approaching from the right edge

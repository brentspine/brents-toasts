# 2.0.16 - 2026-07-23

## Added

- Demo footer now displays repository stats: owner avatar with profile link, open issue count, fork count, watcher count (each linking to the respective GitHub page), and relative last commit time with absolute timestamp on hover.

## Changed

- GitHub API fetch consolidated into a single `loadGithubRepoInfo()` call that populates both the header star badge and footer stats, reducing redundant requests.

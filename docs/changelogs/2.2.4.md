# 2.2.4 - 2026-07-24

## Added

- `theme` option for `showToast()` and `configure()` to customize toast appearance (background, text color, action button color, close icon) via JS API or CSS custom properties (`--bt-background`, `--bt-text`, `--bt-details-background`, `--bt-action-color`, `--bt-close-icon`). Per-toast themes merge key-by-key over library-wide defaults.
- Close icon color now auto-picks dark or light for contrast against the toast's `color`, with `theme.closeIcon` to override.
- `ToastBuilder.withTheme()` method.

## Changed

- CSS custom properties now control toast card background, text color, details block background, and action button text color (previously hardcoded). Existing styling unaffected unless you use the new variables.

# 2.4.10 - 2026-08-05

[![Socket Security](https://badge.socket.dev/npm/package/brents-toasts/2.4.10)](https://socket.dev/npm/package/brents-toasts/overview/2.4.10)

## Changed

- Documentation: replace em dashes (`—`) with hyphens (`-`) throughout README, docs, and code comments for consistency
- Demo: markdown parser now supports link-wrapped images (e.g. Socket Security badge), plain images, and plain links; `MarkdownView` renders them correctly with `<img>` and `<a>` elements
- Progress bar: add `label` option for accessible name (defaults to locale's "Progress" string); bar now renders with `role="progressbar"` and `aria-valuenow` kept in sync
- `promise()` lifecycle: add `timeout` option to show an error/timeout state if promise doesn't settle within specified time; library-wide default via `configure({ promiseTimeout })`
- Demo options schema: document new `promiseTimeout` config and progress bar `label` option
- Changelog generation: prepend Socket Security badge and append stats badges (stars, issues, downloads, coverage, npm version) to each release entry

## Added

- Markdown parser spec and view component tests covering badge rendering and link/image parsing

## Removed

- `SUPPLY_CHAIN_RISK.md` (supply chain audit report removed from repo)

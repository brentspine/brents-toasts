# 2.1.3 - 2026-07-23

## Added

- Localization support with auto-detection based on `navigator.language`. Bundled language packs: `en` (default), `de`, `es`, `fr`.
- `locale` config option to force a specific bundled language pack instead of auto-detecting.
- `translations` config option to override individual translated strings on top of the resolved locale.
- `ToastLocales` export and `ToastTranslations` type for accessing/extending translation packs.
- Built-in button/label text now respects the configured/detected locale: `closeButton()`, `detailsCopyButton()`, and `confirmButton()` now default to translated strings instead of English hardcodes.

## Changed

- `closeButton()`, `detailsCopyButton()`, and `confirmButton()` label parameters are now optional and default to locale-specific translations when omitted (previously had hardcoded English defaults).
- The snackbar region's `aria-label` is now translatable and updates when `configure()` is called with a new locale.

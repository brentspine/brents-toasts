## Added

- `severity` option (`ToastSeverity.INFO` / `SUCCESS` / `WARNING` / `ERROR`) to control toast semantics — drives `role`/`aria-live` independently of color, with `WARNING`/`ERROR` rendering `role="alert"` and `INFO`/`SUCCESS` rendering `role="status"`. Set per-toast or configure library-wide; builder shorthands `.asInfo()` / `.asSuccess()` / `.asWarning()` / `.asError()` now set severity instead of just color.
- `colors` config option — a `ToastSeverity` → default color palette (defaults to bundled `ToastColor`). Unset `color` now resolves to `colors[severity]` instead of a hard-coded default, so `severity: ToastSeverity.WARNING` alone gets both the right look and the right role without needing `color` set too. Also supplies default colors for `promise()` outcomes.
- `pauseOnPageHidden` option to pause toast timers while the page is hidden (tab switched away, window minimized), independent of `pauseOnHover` — either trigger pausing is enough to stop the countdown. Set per-toast or configure library-wide.
- `PagesStatsService` in demo to link to the separately-deployed `brentspine.github.io` repo (shows demo deployment timestamp in footer).
- `ToastSeverity` enum export for imports alongside `ToastColor`.
- Release workflow now validates that tags are cut from `main` (prevents sync issues if accidentally pushed from a feature branch) and warms unpkg CDN cache post-publish.
- Dependabot configuration for automated dependency updates (npm, GitHub Actions).
- Localized position names appended to snackbar region `aria-label`s so screen readers can distinguish simultaneously-visible regions (e.g. "Notifications, top right" vs. "Notifications, bottom center").

## Changed

- `.asInfo()` / `.asSuccess()` / `.asWarning()` / `.asError()` builder methods now call `.withSeverity()` instead of `.withColor()` — they set both semantics and default color, not just color.
- `pauseOnHover` now also pauses on keyboard/screen-reader focus (tabbing into the toast or its contents); hover and focus are tracked independently but either pausing stops the countdown.
- Demo: migrated from deprecated `monaco.languages.typescript.*` to `monaco.typescript.*` API.
- README: ROADMAP link commented out (design docs relocated).
- Changelog/stats badges now HTML-commented (cleaner markdown readability).
- Documentation updated throughout to reference `severity` as the accessibility/role driver, with `color` as purely presentational.

## Removed

- `SUPPLY_CHAIN_RISK.md` (supply chain audit removed from repo).

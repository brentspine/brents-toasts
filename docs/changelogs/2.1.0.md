# 2.1.0 - 2026-07-23

## Added

- Changelog generation for minor and major releases now includes changelogs from earlier versions in the same cycle as context, enabling more cohesive release notes that reflect the full arc of changes rather than just the diff since the last tag.

## Changed

- Demo footer: removed "Page config: maxToasts" display.
- "Last commit" link in demo footer now points to the commits page instead of being plain text.

## Fixed

- Changelog generation cost calculation now accounts for context changelog size in addition to diff size.

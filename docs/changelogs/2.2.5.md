# 2.2.5 - 2026-07-24

## Changed

- `title`, button labels, and the details toggle now honor line breaks: literal `\n` or `<br>`/`<br/>` in the string render as real line breaks, while remaining plain text (unaffected by `allowHtml`). This applies to all button types (top-level buttons, step buttons, the auto-added details toggle).

# 2.2.10 - 2026-07-26

## Fixed

- Navigation to the Playground route now properly scrolls to fragment targets (e.g. `#examples`) after the CodeEditor's Monaco instance finishes loading, preventing misaligned scroll positions.
- Clicking "Playground" or "Examples" nav links now scrolls correctly even on same-URL navigations (e.g. re-clicking "Examples" while already viewing that section).
- Color picker in the Playground no longer modifies the code snippet; picking a color and copying its hex is now a standalone utility.
- Trying multiple examples in quick succession no longer clobbers the original user code when undoing.

## Changed

- Switched from hash-based routing (`/#/playground`) to path-based routing (`/playground`) for cleaner URLs.
- Color picker now displays a dedicated "Copy" button instead of auto-inserting `.withColor()` calls into the code.
- Improved step-button example code to include a realistic `onClick` handler.

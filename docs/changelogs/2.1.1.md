# 2.1.1 - 2026-07-23

## Added
- `Toasts.closeButton()` / `ToastBuilder.withCloseButton()` — ready-made "Close" button factory for dismissing toasts, with translatable `label` parameter (defaults to `"Close"`).
- `detailsCopyableSingle` option — hides "Copy" buttons on single-item details by default (override with `true` to show them), since a lone visible value rarely needs copying.

## Changed
- Close button now reserves full width on hover without resizing the toast, preventing layout shift on closable toasts.

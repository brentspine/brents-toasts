# 2.4.5 - 2026-08-03

## Added

- `ToastTransition` enum with `FADE`, `SHAKE_LR`, and `NONE` options for animating toast updates, replacing the boolean `transition` option.
- `registerToastTransition()` function to define custom transition animations.
- `getToastTransition()` function to retrieve registered transitions.
- `ToastTransitionValue` and `ToastTransitionDefinition` types for type-safe custom transitions.

## Changed

- `ToastOptions.transition` now accepts `ToastTransitionValue` instead of `boolean`: pass `ToastTransition.FADE` (crossfade), `ToastTransition.SHAKE_LR` (shake left-right), or `ToastTransition.NONE`/omit for instant application.
- `ToastBuilder.withTransition()` now accepts `ToastTransitionValue` with default `ToastTransition.FADE`.
- `promise()` outcomes can now specify different transitions per-outcome (e.g., fade on success, shake on error).
- Unregistered transition names now fall back to `FADE` with a one-time console warning instead of failing silently.

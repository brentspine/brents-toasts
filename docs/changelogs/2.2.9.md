# 2.2.9 - 2026-07-26

## Changed

- Playground examples now show an undo button, allowing reversal of "Try it out" clicks to restore prior editor state.
- Example cards highlight with a brief glow animation when navigated to via deep link, but only on first visit.
- Playground nav links now distinguish between the "Playground" and "Examples" sections via scroll position, since both point to the same route.
- Code editor suggestion/hover widgets now use `position: fixed` to escape their container's bounding box near the bottom of the viewport.

## Added

- Color picker in the Playground editor toolbar for quick hex color insertion via `.withColor(...)` without manual typing.
- Copy feedback on example cards now shows "Copied!" temporarily, matching the main editor's behavior.
- Example code snippets updated to demonstrate `onClose` callbacks more clearly.

# 2.2.2 - 2026-07-24

## Added

- Progress bar feature for toasts: `progress` option on `ToastOptions` and `ToastsConfig`, with detailed `ToastProgressOptions` for customization (position, origin, fill/drain mode, colors, height). Synced to auto-dismiss countdown and respects pause/resume/reset timer operations.
- `withProgress()` builder method on `ToastBuilder`.
- `ToastProgressOptions` type exported from main entry point.

## Changed

- Bumped version to 2.2.2.

# 2.3.0 - 2026-07-26

## Added

- **Multiple `Toasts` instances can now safely share a snackbar** — same-position instances (e.g. all defaulting to `BOTTOM_CENTER`) coordinate ownership, so removing a toast via one instance correctly delegates to whichever instance created it, preserving that instance's `onClose` callback, timer state, and exit animation.
- **`removeAllToasts()` now queries the DOM directly** to dismiss toasts across all instances sharing any snackbar, not just ones tracked in the calling instance's internal map.

## Fixed

- Eviction now picks the globally oldest toast across all instances sharing a snackbar, not just the oldest within a single instance.
- Cross-instance toast removal now uses the owning instance's animation and onClose handler instead of falling back to the removing instance's configuration.

## Added

- `icon` option and `ToastIcon` enum — opt-in icon rendered next to the message, with built-in severity icons, image URLs, CSS classes, custom DOM nodes, or renderer functions. `promise()` automatically swaps in pending/success/error icons when `promiseIcons: true`.
- `layout` option (`ToastLayout.DEFAULT` / `PROMINENT`) — mutually-exclusive named looks; `modifiers` option for composable design tweaks (13 total: density, close-button treatment, width, icon animation, etc.) stacked on top of layouts or used independently.
- `minVisibleDuration` option — prevents premature dismissal by playing a shake animation and deferring user-triggered removals until the minimum duration elapses; timeout/eviction removals always succeed immediately.
- `dismissOnClick` option — separate control for whether clicking the toast body dismisses it, independent of the close icon; when false, the close icon renders permanently visible instead of hover-revealed.
- `id` option — custom toast id instead of auto-generated; collision detection with a warning fallback.
- `source` option — grouping label for bulk dismissal via `clearBySource(source)` without manual id tracking.
- `ToastCloseReason` type — `onClose` callback now receives the dismissal reason (click, timeout, eviction, promise auto-close, or direct `removeToast()`).
- `injectLayoutStyles` config option — opt out of positioning/stacking CSS injection for strict CSP or custom layout systems; pairs with existing `injectStyles: false`.
- GitHub issue templates (bug report, feature request, documentation) with guided triage workflow.
- `SECURITY.md` — vulnerability reporting policy and scope.
- Demo: live-rendered documentation page pulling guides from `docs/guide/*.md` via GitHub raw content API, with left-nav manifest and Monaco code editor with auto-completed library API.
- Demo: 20 runnable Playground examples covering all major features (positions, timers, incremental updates, events, localization, icons, layouts, promise, confirm flows, bulk actions, boss fight, etc.).
- Demo: generated Monaco lib types (auto-synced from `dist/index.d.ts` to prevent drift) for Playground sandbox autocomplete.
- `demo.cmd` — Windows shell script for one-command dev setup (builds library, installs demo deps, starts dev server).
- CDN recommendation shift to jsDelivr with unpkg as documented alternative (both serve the same UMD build).

## Changed

- README: Install section now flags npm as recommended, adds yarn variant, and clarifies CDN options.
- `pauseOnHover` now also pauses on keyboard/screen-reader focus (tabbing into the toast or its contents); hover and focus tracked independently but either trigger pausing.
- Demo favicon and styling updates.
- Demo vitest config improvements for better unit test integration.
- Documentation expanded throughout with icons, layouts, and live examples.

## Removed

- `SUPPLY_CHAIN_RISK.md` (already removed in 2.5.1).

# 2.2.0 - 2026-07-24

## Added

- **`configurePosition(position, { maxToasts?, evictOldest? })`** method to override `maxToasts` and `evictOldest` per position, layered on top of the global config.
- **`positionConfig` public field** — a `Map<ToastPositionValue, PositionConfig>` storing per-position overrides.
- **`PositionConfig` type** exported for consumers.
- **All six toast positions** (TOP_CENTER, TOP_LEFT, TOP_RIGHT, BOTTOM_CENTER, BOTTOM_LEFT, BOTTOM_RIGHT) now fully implemented with dynamic stacking and alignment.
- **Timer control API:** `pauseToastTimer()`, `resumeToastTimer()`, `resetToastTimer()`, `extendToastTimer()`, `removeToastTimer()`, and `getToastTimer(id)` for managing auto-dismiss countdowns.
- **`pauseOnHover` option** (defaults `true`) to pause/resume timers on hover.
- **`data` option** and **`getToastData(id)` / `setToastData(id, data)`** for attaching and reading per-toast metadata.
- **`updateToast(id, update)`, `addToastButton()`, `removeToastButton()`, `addToastDetail()`, `removeToastDetail()`** for modifying toasts in place.
- **`removeAllToasts()` public method** to dismiss all visible toasts at once.
- **Multi-step button primitives:** `Toasts.stepButton()`, `Toasts.confirmButton()`, and `Toasts.detailsCopyButton()` with auto-revert timers and async action support.
- **`ToastButton` and `ToastButtonStep` types** exported for custom button flows.
- **Localization support** with auto-detection and bundled packs (en, de, es, fr); `locale` config and `translations` override option.
- **`ToastLocales` export** and `ToastTranslations` type for accessing/extending translations.
- Demo UI control to select all six toast positions.
- Demo "More examples" section with shared undo handler using `data` and timer APIs.

## Changed

- **Details copy behavior is now opt-in** — automatic "Copy" buttons removed; use `Toasts.detailsCopyButton()` to add them per item.
- **Close button visual refinement** — accent bar no longer grows on hover; closable toasts reserve trailing margin that collapses when affordance appears.
- **`closeButton()`, `detailsCopyButton()`, `confirmButton()` label parameters now optional** and default to locale-specific translations.
- **Snackbar region `aria-label` is now translatable** and updates when `configure()` is called with a new locale.
- **Toast positioning engine is now edge-agnostic**, supporting stacking from both top and bottom edges.
- **`maxToasts` and `evictOldest` are now per-position overridable** via `configurePosition()`.
- **Details toggle and `detailsCopyButton()` now reset toast timer** to prevent auto-dismiss while user reads expanded content or confirms copy.
- **Toast root DOM structure:** all snackbar containers now nest inside a single `.bt-toasts-root` element on `document.body` instead of each position adding a separate top-level sibling.

## Fixed

- Step buttons (`confirmButton()`, `detailsCopyButton()`, `stepButton()`) now properly disable while async `onClick` handlers are pending.
- Close button no longer causes layout shift on closable toasts.
- Changelog generation now accounts for context changelog size in cost calculation.

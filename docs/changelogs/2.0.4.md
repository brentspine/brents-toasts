# 2.0.4 - 2026-07-22

## Added

- Support for custom DOM content in toasts: `message` parameter now accepts `Node` (e.g. `HTMLElement`, `DocumentFragment`) in addition to strings, allowing fully interactive content without XSS concerns.
- UMD build exports at `window.BrentsToasts` namespace, mirroring npm named exports (`BrentsToasts.toasts`, `BrentsToasts.Toasts`, etc.).
- Comprehensive README with install, usage examples, and API documentation.

## Changed

- `ToastBuilder` and `showToast()` now accept `string | Node` for the message parameter.

## Fixed

- Toast repositioning now happens immediately when a toast is removed, instead of waiting for the fade-out animation to complete, preventing visual overlap during dismissal.
- Position recalculation now excludes toasts currently fading out.
- CSS padding adjustment: moved `padding: 6px 0` from `.bt-toast` to `.bt-toast-content` for better spacing consistency.
- Demo version list now includes "Latest" link at the top.

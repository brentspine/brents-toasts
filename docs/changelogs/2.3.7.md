# 2.3.7 - 2026-08-02

## Added

- `progress.mode: 'manual'` for progress bars driven by `setToastProgress(id, value)` instead of synced to auto-dismiss countdown — useful for real progress (uploads, multi-step jobs) on sticky toasts.
- `progress.value` option to set initial fill fraction for manual mode.
- `setToastProgress(id, value)` method to update a manual progress bar's fill fraction (0-1, clamped).
- `confirmButton()` now supports per-step color customization: `confirmColor`, `pendingColor`, `doneColor`.
- `confirmButton()` now supports `pendingMessage`/`pendingColor` to show custom content while `onConfirm` is pending instead of just disabling buttons.
- `confirmButton()` now supports `doneAction: 'close'` to dismiss the toast after the done flash instead of always restoring original content.

## Changed

- `confirmButton()` now always restores the toast's original `color` on "No" or after the done flash (when `doneAction: 'restore'`), previously only restored message/buttons.
- Manual progress bars no longer hide on sticky toasts (`duration: 0`), unlike fill/drain modes.

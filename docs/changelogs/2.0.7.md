# 2.0.7 - 2026-07-22

## Changed

- Updated demo to showcase both direct API (`toasts.showToast()`) and builder API (`new ToastBuilder()`) styles
- `toasts.showToast()` now accepts options as an object (`{ color, duration, closable }`) instead of positional parameters
- Demo now includes global configuration controls via `toasts.configure()` with `maxToasts`, `color`, `duration`, and `closable` settings

## Added

- `ToastBuilder` class for fluent toast creation with chainable methods (`.withColor()`, `.withDuration()`, `.withClosable()`, `.show()`)
- `toasts.configure()` method to set library-wide defaults for toasts

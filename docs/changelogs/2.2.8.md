# 2.2.8 - 2026-07-25

## Added

- New "Browse examples" section in Playground showing curated code snippets with "Try it out" and "Copy" buttons
- `PlaygroundExample` interface and `examples` array in options.json with 9 feature examples
- Example links on home page feature cards linking to corresponding Playground examples
- `exampleId` field on Feature objects to connect features to examples
- "Examples" navigation link in header pointing to Playground's examples section
- New `CodeEditor` component using Monaco editor for improved code editing in Playground
- Config form state persistence to localStorage, auto-restored on reload
- Playground code snippet persistence to localStorage, auto-restored on reload
- `surpriseMe()` button in Playground to fire a randomized toast
- `Reset` button in Playground to restore default snippet
- Fragment-based scrolling to examples (works with hash routing)
- Link from Playground to Config page in intro hint
- Link from Config page back to Playground
- "Coming soon" notice on Install page; removed copy-paste install method

## Changed

- Install page now shows only npm and CDN methods (copy-paste removed)
- Page title separators changed from em-dash to pipe (`|`)
- Config page copy: added note about localStorage persistence
- Playground's options table now derives selection state from code text itself, allowing hand-edited/pasted code to remain recognized without regeneration
- Code editor in Playground now uses Monaco instead of textarea
- Various copy tweaks: dashes and em-dashes replaced with colons and semicolons for consistency

## Fixed

- Config page now re-applies stored configuration on load without requiring user to click Apply again
- Fragment navigation properly handles double-hash URLs from hash routing
- Changelog page properly sorts versions newest-first despite being stored oldest-first

## Added

- Dependabot configuration for automated weekly dependency updates across npm packages and GitHub Actions.
- `unpkg` CDN cache warm-up step in release workflow to improve first-user experience by pre-priming the CDN before release announcement.

## Changed

- Codecov action upgraded to v7 (from v5) for improved reliability.
- Demo and build tooling dependencies updated: Angular to 22.1.0, Babel to 8.0.1, build tools to latest compatible versions. These are internal/dev dependencies only.
- README: temporarily disabled ROADMAP.md link (commented out pending future updates).

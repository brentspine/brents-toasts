# 2.4.1 - 2026-08-02

## Added

- `titleMode` option to control whether `title` renders stacked (above message, default) or inline (as bold lead-in on message's line). Set per-toast via `ToastOptions.titleMode` or `ToastBuilder.withTitle(title, mode)`, or configure library-wide via `configure({ titleMode })`.
- `ToastBuilder` constructor now accepts optional `message` parameter (defaults to empty string), enabling title-only toasts.
- `ToastQuickActions` utility — a standalone, stateless class providing pre-translated common action words (`yes`, `no`, `ok`, `cancel`, `confirm`, `dismiss`, `undo`, `retry`, `save`, `delete`) in en/de/es/fr, independent of any `Toasts` instance or its locale configuration.
- `ToastBuilder` methods (`withClosable`, `withAllowHtml`, `withAllowLineBreaks`, `withPauseOnHover`) now accept optional boolean argument defaulting to `true`, allowing chainable calls without arguments (e.g., `.withClosable()` instead of `.withClosable(true)`).

## Changed

- `ToastBuilder.withTitle()` now accepts optional second parameter for `titleMode` override per-toast.
